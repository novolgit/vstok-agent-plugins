# Security Policy

Report suspected vulnerabilities privately to `security@novol.dev`. Do not open a public issue containing tokens, repository metadata, customer data, exploit details, or screenshots from a private workspace.

Include the affected component, reproducible steps, expected impact, and a safe contact method. VStok will acknowledge a valid report as soon as practical and coordinate disclosure after remediation.

Never attach `.env` files, OAuth tokens, GitHub App keys, provider credentials, source code from a customer repository, or full MCP execution reports.
